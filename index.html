Synthetic evidence & retrieval evaluation

CorpusLab

A guided research workbench that turns query-first synthetic records into auditable retrieval evaluation. Separates generation intent from relevance, exposes judge disagreements, and measures retrieved evidence separately from the final answer.

  • Fictional scenarios, a fixed clock, and three query categories
  • Isolated model votes, selective adjudication, and temporal-rubric exploration
  • Executable audit checks, browser-local review, and a controlled regression gate

Behavioral model evaluation

Model Atlas

An independent research prototype measuring shared model errors across judging and generation. Builds task-specific behavioral graphs and evaluates recovery choices on held-out examples. The initial pilot is inconclusive about judging-to-generation transfer.

  • Eight-model study with 3,552 scored evaluations via OpenRouter
  • Source-level uncertainty and held-out comparisons beyond average scores
  • Interactive, read-only demo with explicit limitations and reproducible analysis

Tool call evaluation framework

ToolEval

A framework for evaluating how LLM agents select, parameterize, and compose tool calls. Measures tool selection accuracy, parameter correctness, regression when new tools are added, and interaction effects between tools using Shapley-based metrics.

  • Four-step pipeline: existing baseline, new tool baseline, reverse check, forward check
  • Bidirectional regression: reverse RRS + forward RRS with statistical significance
  • Interaction metrics: dominance index, routing entropy, Shapley interaction

Synthetic evaluation data pipeline

SynthEval

A pipeline for generating synthetic evaluation tasks for tool-using agents. Expands hand-authored seed tasks via paraphrase, analogy, and composition strategies, then validates with a multi-judge panel for ground truth quality.

  • Three expansion strategies with embedding-based dedup
  • Three-judge validation with debate resolution
  • Sentinel validation for 100% ground truth recall

  • Automated ground truth updates with full audit trail

About

About

Applied scientist studying model behavior and building evaluation-first LLM systems, from model selection to agent reliability.

Background

I'm an Applied Scientist working on machine learning-driven agent systems at scale. My day-to-day involves building evaluation pipelines, designing metrics for agent reliability, and turning messy real-world signals into structured, measurable behaviors. I hold a Ph.D. in Computer Science and have experience spanning deep learning, reinforcement learning, and production LLM systems.

What I care about

I'm interested in what makes an evaluation trustworthy: deliberate coverage, clear decision rules, and evidence that can be inspected. CorpusLab explores label and retrieval quality; Model Atlas studies shared model failures. Across this work, I value clear baselines, held-out evidence, and transparent limitations — not just higher numbers.
